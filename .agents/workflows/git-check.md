description: git-check
---

Review the current changes before any commit, push, or deployment.

1. List all modified, added, and deleted files.
2. Explain the purpose of each relevant change.
3. Check for accidental changes, debug logs, temporary code, unused imports, sensitive files, `.env` files, API keys, tokens, or generated files.
4. Identify potential regressions, broken behavior, or incomplete work.
5. Suggest one clear Conventional Commit message.
6. Do not run git commit, git push, or any deployment command without explicit confirmation.
